# ♟️ XequeWeb

> Jogo de xadrez completo desenvolvido do zero com tecnologias web

## 📖 Sobre o Projeto
O **XequeWeb** é um jogo de xadrez totalmente funcional criado com o objetivo de aplicar e consolidar conceitos fundamentais de desenvolvimento web. Desenvolvido apenas com HTML, CSS e JavaScript puro, sem bibliotecas externas, oferece uma experiência limpa, elegante e acessível diretamente no navegador.

## ✨ Funcionalidades
- ✅ Tabuleiro com cores inspiradas em madeira, fiel ao visual clássico
- ✅ Todas as peças e regras do xadrez implementadas
- ✅ Seleção de peças com destaque visual
- ✅ Indicação de movimentos válidos
- ✅ Alternância entre jogadores
- ✅ Design responsivo — funciona em computadores e celulares
- ✅ Efeitos visuais e transições suaves

## 🛠️ Tecnologias
- **HTML5** — Estrutura do tabuleiro e elementos
- **CSS3** — Estilização, layout em Grid e responsividade
- **JavaScript** — Lógica do jogo, regras e interatividade
